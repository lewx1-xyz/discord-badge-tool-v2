# Discord Badge Tool — Lewx1

A Python tool for experimenting with Discord game activity and playtime tracking.

## Features

- **Playtime mode:** Configure playtime values for supported game entries.
- **Game activity mode:** Test game activity event handling.
- **Authentication settings:** Manage locally configured authentication data.
- **Refresh options:** Update authentication settings when needed.

## Requirements

- Python 3.10 or newer
- No additional Python packages required for the standard-library components

## Setup

1. Install Python 3.10 or newer.
2. Place the project files in a local folder.
3. Open a terminal in that folder.
4. Run:

   ```bash
   python activity
   ```

5. Follow the prompts displayed by the program.

## Configuration

Configuration data may be stored locally in `science_state.json`.

**Security:** Never share your Discord account token, session cookies, or other authentication credentials. Avoid entering credentials into untrusted scripts.

## Important Notes

- This project is unofficial and is not affiliated with Discord.
- Automated activity reporting may violate Discord's Terms of Service and could result in account restrictions.
- Discord may change its APIs at any time.
- No guarantee is made that activity or badges will update.
